# Guia de Estudo de HTML

Projeto da disciplina **Desenvolvimento Front-end para Web** (UNIPÊ). Site 100% em HTML, sem CSS e sem JavaScript, com revisão de HTML semântico para a prova.

## Páginas (pasta `html/`)
- `index.html`, `semantica.html`, `tags.html`, `multimidia.html`, `planejamento.html`

## Pastas
`html/` páginas · `img/` imagens · `audio/` áudio local · `video/` reservada

## Como abrir
Abra `html/index.html` no navegador.
